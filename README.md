Задание 1

Использовал паттерн Webpack Module Federation, так как:
1) Есть сквозные компоненты, которые используются в нескольких микрофронтендах.
2) Используется 1 фреймворк для нескольких сервисов
3) На мой взгляд - реализация быстрее и требует меньших компетенций при развёртывании, чем Single SPA

Разделение:
Остаток монолита (сервис занимается оркестрацией). Бывшее ядро монолита

1) auth-microfrontend (сервис аутентификации пользователя). Отвечает за регистрацию пользователя и его авторизацию.
2) picture-microfrontend (сервис работы с фото и пользовательскими реакциями). Самый высоконагруженный сервис, отвечает за CRUD операции c фото. Хранит фото с реакциями.
3) profile-microfrontend (сервис для настройки профиля пользователя). Сервис для редактирования и хранения профиля.
